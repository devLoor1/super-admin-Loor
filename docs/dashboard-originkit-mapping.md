## Classification

| Area | Classification | Decision |

| SUPER ADMIN sidebar identity | A. KEEP NATIVE FRONTEND | Static Lucide Layers + accessible brand link. Persistent navigation needs instant recognition, not repeated WebGL motion. |

| KPI icon treatments | A. KEEP NATIVE FRONTEND | Consistent Lucide line icons, CSS tiles and module tones are clearer and easier to extend than unrelated asset sets. |
| Empty-state illustrations | B. ORIGINKIT CANDIDATE | Optional low-priority line-art family. Preserve explicit text and avoid implying real records or activity. |
| Dashboard decorative background | C. ORIGINKIT NOT RECOMMENDED | Existing quiet SVG/CSS spheres suffice. Animated shader backgrounds would distract from dense administrative content. |
| Operational-status visuals | C. ORIGINKIT NOT RECOMMENDED | Status must come from authoritative data; native text + semantic indicators are preferable to decorative motion. |
| Charts, tables, search, menus and forms | A. KEEP NATIVE FRONTEND | Preserve semantics, keyboard behavior and data meaning. Illustration assets must not replace controls or encode fabricated business values. |
| Full-screen dashboard transitions / typing headings | C. ORIGINKIT NOT RECOMMENDED | Operational headings and navigation should appear immediately; keep the approved motion on Login only. |
