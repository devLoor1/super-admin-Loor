# LOOR — demonstração local da vitrine

Snapshot portátil do mock, com editor e vitrine pública. Somente demonstração local; nenhuma API operacional ou persistência real.

Execute `demo-local.cmd` na raiz para instalar as dependências ausentes, compilar e iniciar em 127.0.0.1:5192. Leia [HANDOFF-DEMO.md](HANDOFF-DEMO.md).

O snapshot preserva os arquivos do protótipo aprovado e omite relatórios operacionais históricos/evidências de contas. A origem permanece intacta. O commit de transporte não inclui histórico anterior, para não transportar esses documentos por ancestrais Git.

Não publicar este mock, não fazer merge em main/dev e não retomar testes de participantes. Veja também [MOCK.md](MOCK.md) e [AGENTS.md](AGENTS.md).
